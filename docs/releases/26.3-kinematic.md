# TenorClef 26.3 / 0.22.2 — Kinematic Experimental

Suggested GitHub release tag: `v0.22.2-mc26.3-kinematic.1` (prerelease).

## Install

Install Minecraft **26.3**, **Fabric Loader 0.19.5**, and **Java 25**.
Download `tenorclef-mc26.3-0.22.2-kinematic.zip` and copy its `mods/` contents into
your Minecraft profile's `mods/` directory:

| File | Purpose |
| --- | --- |
| `altoclef-26.3-0.22.2-kinematic.jar` | Full TenorClef with the kinematic startup preset |
| `baritone-unoptimized-fabric-ostinato-26.3.jar` | Matching Ostinato pathfinding and movement implementation |
| `fabric-api-0.161.0+26.3.jar` | Fabric API dependency |

Remove the regular TenorClef/AltoClef jar and older duplicates of these mods.
This variant uses the same `altoclef` mod ID; install only one TenorClef jar.
Tungsten is optional and unnecessary for this preset. Do not put the distribution
ZIP itself in `mods/`; extract it first.

The variant enables `kinematicTravel` and selects `movementBackend baritone`
at startup, including when an old profile selected Tungsten. No JVM option is
required. An existing `-Dtenorclef.kinematic=false` overrides the enabled default;
remove that option to use kinematic travel. Manual in-game changes work until the
next launch, when the preset is applied again.

Commands: `@get blaze_rod 3`, `@stop`. Query settings with
`#set movementBackend` and `#set kinematicTravel`.

## What changed

The original checkpoint's runtime classes are preserved byte for byte. A small
Fabric initializer, packaged into this full alternative jar, selects the release
preset before TenorClef initializes its title-screen settings. The mod metadata
identifies the kinematic variant. The original regular release remains unchanged.
Source and the packaging command are in `tools/release/`.

## Validation and limitations

The original controller ran in a recreated Survival/Normal world, with mobs and
keepInventory enabled. A JFR profile captured `KinematicController.rollout`.
The bot built a portal, entered the Nether, and found a blaze-spawner target.
The user stopped the run after 11m 27.591s with 0/3 rods. The saved world is kept
separately and is not included in this release. This is an experimental prerelease;
the blaze-rod task remains incomplete. Historical 1.16.1 benchmark numbers do not
establish 26.3 performance.

See `VALIDATION.md` in the downloadable bundle for checks performed on this
variant. `SHA256SUMS.txt` covers the shipped jars. On Linux/macOS, run
`sha256sum -c SHA256SUMS.txt` from the extracted bundle directory.
