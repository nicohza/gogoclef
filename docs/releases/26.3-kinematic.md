# TenorClef 26.3 — Kinematic Experimental .2

Release tag: `v0.22.2-mc26.3-kinematic.2` (prerelease).
Game code: `a7e2d0dae1fd3d37eeb8b73259409f42d9597700`.

## Install

Requires **Minecraft 26.3**, **Fabric Loader 0.19.5**, and **Java 25**.
Download `tenorclef-mc26.3-0.22.2-kinematic.2.zip`, extract it, and copy the three
jars from its `mods/` folder into your Minecraft profile's `mods/` folder:

- `altoclef-26.3-0.22.2-kinematic.2.jar`
- `baritone-unoptimized-fabric-ostinato-26.3.jar`
- `fabric-api-0.161.0+26.3.jar`

Replace older AltoClef/TenorClef, Baritone/Ostinato, and Fabric API jars to avoid
duplicate mods. Remove Tungsten from this kinematic profile. Do not place the ZIP
or Fabric Loader installer in `mods/`; install Fabric Loader through your launcher.

Kinematic travel is enabled automatically and the Baritone backend is selected
at startup. Remove any `-Dtenorclef.kinematic=false` launcher option to use the
preset. Check settings using `#set movementBackend` and `#set kinematicTravel`.
Start with `@get ender_pearl 3`; stop with `@stop`.

## Changes since .1

- Ender-pearl collection uses the Nether and keeps an active portal trip from
  being interrupted by a distant Overworld enderman.
- Air recovery starts at half air and continues through recovery.
- When an underwater ceiling blocks ascent, the bot searches for a nearby open
  route to breathable air and checks clearance while following it.
- Normal upward swimming remains available in open water.

## Validation and limitations

A fresh Minecraft 26.3 kinematic pearl trial completed **3/3 pearls**, with **zero
deaths**, in **4m 27.907s**. This single trial preceded the added ceiling-route
repair. The updated surfacing code separately passed covered-water and open-water
checks without health loss. The 26.3 build and compatibility checks for 1.21.4
and 1.16.1 each passed **160 tests**. Only 26.3 jars are included here.

This remains experimental. Local escape searches are bounded and cannot guarantee
escape from every underwater cave. The earlier blaze-rod trial was stopped at
0/3 rods; it is not a completed benchmark. Historical 1.16.1 timings do not establish
26.3 performance.

The full validated game jar is preserved byte for byte except for mod metadata;
a small Fabric initializer enables the startup preset. See `VALIDATION.md` for
packaging checks and `SHA256SUMS.txt` for shipped-jar checksums. On Linux/macOS,
run `sha256sum -c SHA256SUMS.txt` from the extracted bundle directory.
