## Issues exposed

1. **Underwater pursuit did not recover before drowning.** Screenshots show
   `KillEndermanTask → KillEntitiesTask → KillEntityTask → GetToEntityTask`
   approaching an enderman underwater. The evidence does not isolate the cause
   to the kinematic controller, pursuit goal, or survival override.
2. **Incorrect dimension destination when no enderman is tracked.**
   `TaskCatalogue.java` registers `ender_pearl` with the default Overworld
   restriction. `CataloguedResource.getResource` reapplies it after
   `KillEndermanTask`'s constructor selects Nether. Consequently,
   `getToCorrectDimensionTask` returns an Overworld task while already there.
   Source inspection and the packaged catalogue bytecode confirm the override;
   the task overlay shows its in-game effect.

Both issues remain unresolved in the tested release. This run supplies a
reproduction for continued Minecraft 26.3 kinematic development.
